# Curso-de-coder

Elegí red interna porque para esta actividad no era necesario que conecte la maquina virtual a internet, entonces utilizando el modo NAT tendría acceso a internet aunque no permitiría que un externo entre a la maquina, igualmente es innecesaria la conexión a internet porque solamente tenia que configurar la maquina en si, por la misma razón tampoco elegí el modo Adaptador Puente porque aparte de que te habilita el uso de internet, también te hace visible hacia el exterior, como si fueras un dispositivo más, entonces pondría en peligro el laboratorio seguro sin ningún tipo de beneficio adicional.
El modo Red Interna protege la maquina real al mantenerla separada de la maquina virtual, esto permite experimentar con la virtual de forma segura ya que nada que salga "mal" pueda pasarse para el host.

Permisos del archivo:
Es importante tener los archivos importantes con los permisos pertinentes para que otro usuario no pueda acceder a los mismos o si lo hace, que lo haga con el permiso del dueño del archivo.
